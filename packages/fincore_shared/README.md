# fincore_shared

Este pacote abriga funções utilitárias puramente Dart (sem dependências de widgets ou UI) compartilhadas por múltiplos produtos ou pacotes da FINCORE Platform.

> **Regra de Evolução (003: Item 2.1)**: Este pacote deve permanecer vazio de lógica inicial até que funções e extensões repetidas em múltiplos domínios exijam extração centralizada.

# fincore_design_system

Este pacote abriga os tokens de design, temas, cores, tipografias e componentes visuais do Flutter reutilizáveis por múltiplos produtos ou módulos da FINCORE Platform.

> **Regra de Evolução (003: Item 2.1)**: Este pacote deve permanecer vazio de lógica inicial até que componentes visuais repetidos em múltiplos domínios exijam extração centralizada.
